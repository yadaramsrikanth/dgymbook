PROJECT DESCRIPTION:
    This is a Wordle-style word guessing game built using React.js. The game allows users to guess a 5-letter word in 6 attempts while receiving color-coded feedback for each letter. It         includes a clean UI, proper state management, and responsive design for mobile, tablet, and desktop.


STEPS TO RUN THE PROJECT:
  1. git clone [git hub repository url]
  2. cd [directory_name]
  3. npm install
  4. npm start



ADDITIONAL FEAUTURES:

1.Green → Correct letter & correct position
2. Yellow → Correct letter but wrong position
3. Gray → Letter not in the word
4 Valid Word Check: Only allows real 5-letter words from a predefined list.
5.Game Over Message: Displays a win or lose message when the game ends.
6.New Game Button: Allows users to restart the game with a new word.
7.Mobile & Tablet Friendly: Fully responsive design for different screen sizes.
8.Optimized State Management: Uses React's useState to handle game logic efficiently.
